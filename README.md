# ごうかくクエスト（仮）

集中した時間だけ冒険マップを進み、志望校の城をめざす受験生の応援タイマー

**▶ 使ってみる: https://ytakahashi2020.github.io/gokaku-quest/**

## どんなもの

- テーマは「誰かを喜ばせたい・応援したい」
- 対象は試験・受験をがんばる人
- 仕組みは集中タイマー＋ごほうび
- メイン画面は10分・25分・50分から選んでスタート
- ごほうびは集中した分数だけ進む「志望校まですごろく」
- 道中のマスで応援イベント、ゴールは「合格の門（お城）」
- 見た目はポップな冒険マップ（青空・草原、ひよこのコマ）
- 進み具合はブラウザに保存

## 作り方

AIでアイデアをカタチに！ で、AIと相談しながらアイディアを練り、AIが作ったコードをもとに公開しました。
相談の記録は [IDEA.md](IDEA.md) にあります。

## ファイル

- `index.html` … アプリ本体（このファイル1つで動きます）
- `IDEA.md` … アイディアを練ったときの記録
